## DaisyUI remains replaceable

The default theme uses Tailwind and DaisyUI for visible elements. Semantic data such as `tone: muted` remains independent from them. A later theme can express that meaning differently without rewriting content.

Storybook also presents reusable components in isolation. This makes further development easier without rebuilding a content page for every detail.
