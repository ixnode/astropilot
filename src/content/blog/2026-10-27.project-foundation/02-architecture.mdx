## Deliberately small

The project uses Astro's routing, Markdown processing, and static build directly wherever possible. Custom logic is limited to relating files, deriving URL segments, and sorting sections.

That keeps the project understandable when it is used in a website of its own: content is maintained, checked, and versioned together in the repository.
