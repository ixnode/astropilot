## The foundation remains the same

Sproutsite remains an **agent-ready, Markdown-first static CMS powered by Astro and TypeScript**. Page structures, copy, and settings are maintained as traceable files in the repository. Markdown and YAML provide the foundation; documented components extend content where a layout needs more than running text.

External coding agents such as Codex or Claude Code can work on these files and develop content, components, and pages. Sproutsite itself contains no AI agent or traditional CMS administration backend. It provides the technical foundation; Astro generates static pages that can be published without a CMS server runtime.

The new name does not change that approach. It gives it a distinct identity: **Sproutsite — The Agent-Ready Static CMS**.

To explore the project further, start with the [documentation](/dokumentation/) and browse the available building blocks, variants, and examples in the [showcase](/showcase/).
