## How a page is assembled

A `page.yaml` activates a directory as a page and supplies HTML metadata. An optional `hero.md` contains the visible introduction, including the H1. Numbered Markdown files are then rendered as semantic sections.

Content, URL, order, and the role of every building block remain immediately visible in the file system.
