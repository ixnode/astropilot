## A framework for Astro components

Developers provide the theme and reusable components. Editors maintain Markdown, page metadata, and global configuration. This makes it possible to present DaisyUI or Tailwind building blocks consistently.

The result remains a static website without additional runtime services.

Sproutsite is an npm-based developer tool: an agent-ready, Markdown-first static CMS powered by Astro and TypeScript. Content and page structures remain versionable files. The published website requires no CMS server runtime.

Sproutsite contains no AI agent itself. External coding agents such as Codex or Claude Code support the creation and editing of content, components, and pages. Responsibility and approval remain with the project team.
