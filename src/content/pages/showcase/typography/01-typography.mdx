## Inhaltstypografie

Normales Markdown bleibt der Standard für Inhalte. Es erhält im Theme eine lesbare Typografie und benötigt weder Klassen noch HTML-Fragmente. Jedes Beispiel zeigt zunächst die Vorschau; unter „Code“ findest du den passenden Markdown-Ausschnitt zum Einfügen in eine bestehende Inhaltsdatei. Die Vorschau/Code-Tabs selbst gehören nur zur Darstellung der Beispiele.

**Atomic Design:** Übergreifende Theme-Grundlage. Die Markdown-Typografie ist keine eigene Astro-Komponente.

CSS-Pfade unter `src/themes/default/styles/foundation/`: `fonts.css` und `prose.css`.

Die sichtbare Hauptüberschrift kommt aus dem Seitenlayout; Inhaltsabschnitte beginnen mit h2. Die Beispiele dieser Seite stehen unter h3. Hier zeigen h4 bis h6 die weitere Gliederung, ohne eine Ebene zu überspringen.

### Aufzählungen und nummerierte Listen

Aufzählungen gruppieren gleichrangige Punkte. Nummerierte Listen machen eine Reihenfolge deutlich; Unterpunkte ergänzen einen einzelnen Schritt.

<Tabs label="Aufzählungen und nummerierte Listen: Vorschau und Code" variant="border">
    <Tab title="Vorschau">
        #### Auf einen Blick

        - Texte bleiben in Markdown gepflegt.
        - Einstellungen stehen in YAML-Dateien.
        - Geprüfte Komponenten übernehmen die Darstellung.

        #### Schritt für Schritt

        1. Eine Inhaltsdatei öffnen.
        2. Den Inhalt bearbeiten.
            - Aussagekräftige Überschriften verwenden.
            - Links und Alternativtexte prüfen.
        3. Das Ergebnis in der Vorschau kontrollieren.

### Inline-Code und sprachabhängige Codeblöcke

Inline-Code kennzeichnet Dateinamen oder kurze technische Begriffe. Mehrzeiliger Code erhält eine Sprachangabe für das Syntaxhighlighting. Der Code-Tab zeigt auch die dafür benötigten Markdown-Zeichen.

<Tabs label="Inline-Code und sprachabhängige Codeblöcke: Vorschau und Code" variant="border">
    <Tab title="Vorschau">

        ```typescript

            title: 'Sproutsite',
            published: true,
        };

        const description: string = page.title;
        ```
