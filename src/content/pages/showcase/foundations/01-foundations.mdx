## Design Foundations

Wie wirken die Farben, Schriften, Abstände, Ecken und Schatten des Themes? Die folgenden Proben machen die gemeinsamen Gestaltungsgrundlagen sichtbar. Unter „Code“ findest du die MDX-Einbindung und einen passenden CSS-Ausschnitt aus dem Baustein. Die CSS-Ausschnitte erklären die Darstellung; die fertige Komponente bringt ihre Styles bereits mit.

Die vollständigen Tokenwerte, Quelldateien und Verwendungsdetails stehen in der [Theme-Dokumentation](/dokumentation/theme/). Die Detailseiten für [Cards](/showcase/cards/), [Alerts](/showcase/alerts/) und [Layout](/showcase/layout/) zeigen die Anwendung der fertigen Bausteine.

**Atomic Design:** Die Gestaltungsgrundlagen gelten für alle Ebenen. Die sichtbaren Proben rendert das Molecule `FoundationSample`.

Komponentenpfad unter `src/themes/default/components/`: `molecules/FoundationSample/`.

### Farben sehen und vergleichen

Die Palette zeigt neutrale Flächen, Markenfarben und Statusfarben direkt nebeneinander. Jede Farbfläche ist beschriftet; ihre Farbe kommt aus dem Theme.

<Tabs label="Farben sehen und vergleichen: Vorschau und Code" variant="border">
    <Tab title="Vorschau">
        <FoundationSample kind="colors" />
    </Tab>
    <Tab title="Code">
        ````mdx
        import { FoundationSample } from 'astropilot/components';

        <FoundationSample kind="colors" />
        ````

        Die Darstellung verwendet unter anderem diesen CSS-Ausschnitt:

        ````css
        .ap-foundation-sample__swatch--primary {
            background-color: var(--color-primary);
        }

        .ap-foundation-sample__swatch--secondary {
            background-color: var(--color-secondary);
        }

        .ap-foundation-sample__swatch--accent {
            background-color: var(--color-accent);
        }
        ````
    </Tab>

</Tabs>

### Schrift und Größen erleben

Die weicheren Formen von Nunito und die Systemschrift lassen sich direkt vergleichen. Die große Schrift passt sich an die Bildschirmbreite an. Die Proben sind Textabsätze, damit die Überschriftenhierarchie der Seite erhalten bleibt.

    <Tab title="Vorschau">
        <FoundationSample kind="type" />
    </Tab>
    <Tab title="Code">
        ````mdx
        import { FoundationSample } from 'astropilot/components';

        <FoundationSample kind="type" />
        ````

        Die Darstellung verwendet unter anderem diesen CSS-Ausschnitt:

        ````css
        .ap-foundation-sample__display {
            font-family: var(--font-heading);
            font-size: var(--text-display);
            font-weight: 700;
            line-height: 1.2;
        }

        .ap-foundation-sample__heading {
            font-family: var(--font-heading);
            font-size: var(--text-heading-2);
            font-weight: 500;
            line-height: 1.2;
        }

            font-family: var(--font-sans);
            line-height: 1.75;
        ````
