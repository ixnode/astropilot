## Tabs

Reiter zeigen zusammengehörige Inhalte abwechselnd an. Probiere die drei Darstellungen aus: Jeder Block arbeitet unabhängig, der Inhalt bleibt normales Markdown. Mit der Tabulatortaste erreichst du den ausgewählten Reiter, mit den Pfeiltasten links und rechts wechselst du ihn. Pos1 und Ende springen zum ersten und letzten Reiter.

### Linie

Eine dezente Linie markiert den ausgewählten Reiter. Dies ist die Standarddarstellung.

<Tabs label="Arbeitsablauf">
    <Tab title="Inhalte">
        #### Inhalte pflegen

        Seiten entstehen aus `page.yaml` und nummerierten Markdown-Dateien.

        - Texte lokal bearbeiten
        - Änderungen in der Vorschau prüfen
        - Inhalte gemeinsam versionieren
    </Tab>
    <Tab title="Prüfen">
        #### Qualität prüfen

        Vor der Veröffentlichung prüfen die vorhandenen Befehle Inhalte und Ausgabe:

        ```sh
        npm run check
        npm run build
        ```
    </Tab>
    <Tab title="Weiterlesen">
        #### Mehr erfahren

        Die [Dokumentation](/dokumentation/) erklärt den Aufbau. Für einen schnellen Start führt der [Einstieg](/dokumentation/einstieg/) durch die Einrichtung.
    </Tab>

</Tabs>

### Box

Die Reiter stehen auf einer gemeinsamen Fläche. Hier ist anfangs der zweite Reiter ausgewählt.

<Tabs label="Vorteile des Frameworks" variant="box" initial={2}>
    <Tab title="Für Autoren">
        #### Vertraute Dateien

        Markdown für Texte, YAML für Einstellungen. Ein CMS-Backend ist nicht erforderlich.
    </Tab>
    <Tab title="Für Entwickler">
        #### Geprüfte Bausteine

        Astro-Komponenten bilden das Layout. Autoren setzen die dokumentierten Bausteine in MDX ein.
    </Tab>
    <Tab title="Für Besucher">
        #### Statische Seiten

        Links und Inhalte werden als HTML ausgeliefert. Ohne JavaScript bleiben alle Tab-Inhalte untereinander lesbar.
    </Tab>

</Tabs>

### Angehoben

Die aktive Registerkarte hebt sich optisch von den anderen Reitern ab. Bei wenig Platz lässt sich die Reiterleiste horizontal scrollen.

<Tabs label="Darstellung und Bedienung" variant="lift">
    <Tab title="Desktop und Mobil">
        #### Platz für den Inhalt

        Die Panels nutzen die verfügbare Breite. Lange Reiterleisten scrollen innerhalb des Bausteins, ohne die gesamte Seite zu verbreitern.
    </Tab>
    <Tab title="Tastaturbedienung">
        #### Ohne Maus wechseln

        Pfeiltasten wählen den benachbarten Reiter. Nach dem letzten folgt wieder der erste. Die Tabulatortaste führt anschließend in das aktive Panel und zu seinen Links.
    </Tab>
    <Tab title="Markdown und Links">
        #### Inhalt wie gewohnt

        **Hervorhebungen**, Listen, Code und [interne Links](/showcase/layout/) können in jedem Panel verwendet werden.
    </Tab>

</Tabs>

### Verwendung in MDX

`label` benennt die Reitergruppe für assistive Technologien, `title` den einzelnen Reiter. `variant` ist optional und erlaubt `border`, `box` oder `lift`. `initial` zählt ab eins und muss auf ein vorhandenes Panel zeigen. Ein `Tab` gehört direkt in einen `Tabs`-Block.

```mdx
import { Tabs, Tab } from 'astropilot/components';

<Tabs label="Produktinformationen" variant="border" initial={1}>
    <Tab title="Überblick">

        Der erste Inhalt mit **Markdown**.

    </Tab>
    <Tab title="Details">

        Weitere Informationen zum Thema.

    </Tab>

</Tabs>
```
