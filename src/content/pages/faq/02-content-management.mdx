## Maintain content

### How do I add a section?

Create a Markdown file in the page directory with a numerical prefix such as `03-new-section.md`. Its content starts with a level-two heading.

### Where do component examples belong?

The theme provides the layout and tested building blocks. New examples for Tailwind or DaisyUI components can be added as clearly scoped theme components and explained through these content pages.
