## General questions

### What does Sproutsite show?

Sproutsite is an agent-ready, Markdown-first static CMS powered by Astro and TypeScript. This demo shows how file-based content, shared layouts, and components work together. The website is generated statically and does not need a CMS server runtime.

### Does Sproutsite include an AI agent?

No. External coding agents such as Codex or Claude Code can create and edit content, components, and pages in the repository. Sproutsite provides the technical foundation but includes neither an AI agent nor a traditional CMS administration backend.

### Why Astro for this kind of website?

Astro delivers static pages efficiently and supports components from different UI approaches. This works well for landing pages and structured content pages.
