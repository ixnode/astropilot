## Projekt lokal starten

Sproutsite benötigt Node.js 24 LTS oder neuer. Die im Repository enthaltene `.nvmrc` legt die getestete Node-Version fest.

```sh
nvm use
npm install
npm run dev
```

Danach ist die Demo unter der vom Astro-Dev-Server ausgegebenen lokalen Adresse verfügbar. Der Entwicklungsserver startet mit `--force`, damit Änderungen an Collections und MDX-Bausteinen zuverlässig neu eingelesen werden.

### Die wichtigsten Ordner

- `src/content/` enthält Website-Konfiguration und Seiteninhalte.
- `src/themes/default/` enthält das Standard-Theme und seine Komponenten.
- `src/lib/sproutsite/` enthält die kleine Inhalts-, URL- und Validierungslogik.
- `src/package/` bildet die spätere öffentliche Paketoberfläche ab.
