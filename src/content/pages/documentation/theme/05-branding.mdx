## Logo und Browser-Icons

Das Sproutsite-Symbol verbindet zwei grüne Blätter mit drei übereinanderliegenden Ebenen in Türkis, Cyan und Blau. Die Wortmarke verwendet die lokal eingebundene Schrift Nunito. Im transparenten Header ist sie weiß, nach dem Scrollen und im Footer dunkel. Name, Navigation und bestehende Seitenfarben bleiben unabhängig davon konfigurierbar.

Alle Dateien liegen unter `src/themes/default/assets/branding/`:

| Datei                                                         | Verwendung                                                     |
| ------------------------------------------------------------- | -------------------------------------------------------------- |
| `logo.svg`                                                    | Symbol und dunkle Wortmarke auf hellen Flächen                 |
| `logo-dark.svg`                                               | Symbol und weiße Wortmarke auf dunklen Flächen                 |
| `logo-monochrome.svg`                                         | Einfarbige Variante für Druck und reduzierte Darstellung       |
| `icon.svg`, `icon-monochrome.svg`                             | Quadratisches Symbol ohne Wortmarke                            |
| `favicon.svg`, `favicon.ico`                                  | Browser-Tab; das ICO enthält 16, 32 und 48 Pixel               |
| `favicon-16x16.png`, `favicon-32x32.png`, `favicon-48x48.png` | Kleine Rastervarianten                                         |
| `apple-touch-icon.png`                                        | Apple Touch Icon mit 180 × 180 Pixeln                          |
| `icon-192x192.png`, `icon-512x512.png`                        | Web-App-Icons auf Navy-Hintergrund                             |
| `social-card.png`                                             | Social-Media-Vorschau der Produktwebsite mit 1200 × 630 Pixeln |

Die SVGs enthalten echte Vektorpfade, auch für die Schrift. Sie benötigen keine externen Schriften oder Bilddaten. Die monochromen SVGs verwenden `currentColor`; als eigenständige Bilddatei ist die Standardfarbe Schwarz. Für weiße Druckvorlagen kann die Farbe im SVG gesetzt werden.

`PageLayout` verknüpft Favicons und Touch-Icon automatisch. Die Standardkonfiguration ergänzt `/site.webmanifest` als statisch erzeugten Astro-Endpunkt mit Website-Name, Sprache und den beiden App-Icons. Auch ein Deployment unter einem Unterpfad wird berücksichtigt. Daraus entsteht keine Offline-App; ein Service Worker wird nicht eingebunden.

### Markenfarben und Pflege

Die Markenfarben stehen als `--color-brand-*` in `styles/foundation/tokens.css`. Sie ergänzen die semantischen UI-Farben, ersetzen diese aber nicht. Grün und Türkis sind Symbolfarben und keine automatisch geeigneten Textfarben auf Weiß.

```sh
npm run branding:generate
npm run format
```

Der Generator `scripts/generate-branding.ts` erzeugt alle Varianten aus denselben Formen und Farben. Die Quelldatei der Schrift und ihre SIL Open Font License liegen unter `scripts/assets/`. Ein normaler Build nutzt die bereits vorhandenen Dateien und lädt keine Schriften oder Logos herunter. Bei einem eigenen Consumer-Theme sollten neben dem Logo auch die Standard-Favicons und App-Icons ersetzt werden.
